### 踩坑：开始游戏瞬间渲染报 `Cannot read properties of undefined (reading 'curve')`
- 现象：菜单态正常，点击「接单出发」后每帧报 `render()` 里 `baseSeg.curve`。
- 根因：`startGame()` 里 `lastTime = performance.now()`，而紧接着那一帧 rAF 的 `now` 时间戳
  **可能早于** `performance.now()`，导致 `dt < 0` → `speed * dt < 0` → `pos` 变成 `-0.05`
  → `Math.floor(pos / segmentLength) % len = -1` → `segments[-1]` 为 undefined。
- 修复（两处最小改动）：
  1. `var dt = Math.max(0, Math.min(0.05, (now - lastTime) / 1000 || 0))`；
  2. `findSegment()` 对负索引做 `(n + len) % len` 安全回绕。
- 教训：**rAF 时间戳与 performance.now() 不保证单调对应**，手动重置 lastTime 时必须钳制 dt 下界。
  调试用 `window.__debug` / `warpRatio` 钩子在验证后已全部移除，最终构建确认无残留。

  结算乘客星级 + 里程费 / 时长费 / 剐蹭扣款明细。
- **关键 bug（本轮画面「像草稿」的真正根因，务必记住）**：
  1. **投影双重 scale**：`drawSprite` 写成 `sx + sc * sp.offset * sw`，但 `sw` 已含 scale
     → 所有 sprite 和车流车挤在路中央（x 集中在 630~690）。正确是 `sx + sp.offset * sw`；
     车流同理 `cx = lerp(screen.x) + car.offset * sw`，**不要乘 cScale**。
  2. **lamp 永不生成**：sprite 循环 `s += 4`，`s % 12` 只会取 0/4/8，被 building/sign/tree 占满，
     默认 `lamp` 分支永远走不到。改成 `s % 24 === 8` 才 tree，其余留给 lamp。
  3. **天际线被路面盖住**：背景层画在 `H*0.66~0.76`，但路面消失点在 `H/2` 附近，楼群完全不可见。
     正确位置 `y:0.40/0.44/0.48`，地标 baseY = `H*0.485`。
  4. 沥青修补痕过密（`(index*7)%11<3`）会形成整幅斑马纹，改 `index%13===0` 且 alpha .028。
  5. 路灯可见距离内太小：单独给 lamp 用 `lb = base*110`（base 已含 190 倍率），其它 sprite 不变。
