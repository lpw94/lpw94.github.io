### 打印 / 导出 PDF（最刚需）
- 之前 `about.css` **完全没有 `@media print`**，打印预览会大面积失效：
  hero 是 `linear-gradient` + 白字（浏览器默认不打印背景 → 白字白底）、
  `.orb` 的 `blur(60px)` 印成灰块、`.stat-num` 用 `background-clip:text` + `color:transparent`
  （打印 = 完全看不见数字）、`.skill-bar` 长度靠渐变（印成空槽）。
- 打印样式做法：
  - 外壳全隐：`.site-bg/.site-header/.sidebar/.music-player/.share-fab/.cursor-fx/.orbs/.caret/.print-bar/.about-footer` + `footer`。
  - hero 改白底黑字 + `border-bottom: 2px solid #4f46e5`，头像 60px，`::after` 高光 `display:none`。
  - `.stat-num` 覆盖回 `background:none; background-clip:border-box; color:#111; -webkit-text-fill-color:#111`。
  - `.skill-bar` 改实色 + `print-color-adjust: exact`（不加这句实色也不打印）。
  - 分页：`.project/.stat/.skill/.intent-item { break-inside: avoid }`，
    **`.card` 要显式写 `break-inside: auto`** —— 项目经验那张卡很长，avoid 会整块推到下一页留大空白；
    `.card-title { break-after: avoid }` 防止标题落单在页尾。
  - `@page { margin: 12mm 10mm }`。
- 页面加「导出 PDF」按钮（`window.print()`），打印时自身隐藏。

### 验证姿势（新增可复用脚本 `print-check.mjs`，放系统 temp）

## 第 25 篇博文：授权 = 勾菜单（admin-api 权限模型收尾）

### 文章
- 文件 `blog-content/25-admin-permission-menu-grant.md`，slug `admin-permission-menu-grant`，分类 backend。
- 主题：admin-api 补齐角色/菜单 CRUD + 用户部分更新 + Alembic 后的权限模型收尾讲解。
- 核心论点：**权限码挂在菜单上而非角色上**，所以「授权 = 勾菜单」；改菜单权限码会波及所有关联角色。
- 26.6 KB / 690 行，14 个二级章节，20 个 python 块 + 若干 tsx/bash/ini 块。

### 写作方法（值得复用）
- **文章里所有数字和输出都来自实测**，不是照着代码"推演"出来的：
  起 uvicorn → curl 打接口 → 把真实 JSON 输出贴进文章。测完把改过的数据还原回种子状态。
- 写完后用脚本逐行比对文章里的 python 代码块与源文件（`grep` 集合比对，跳过 `...`/注释/括号行），
  把"看起来对但其实是我改写的"片段揪出来。误报主要来自 docstring 空行和省略号。
- **表格数字一定要重测**：第一次写的权限矩阵里 viewer 的 `/api/users` 是 200，
  因为那是我中途给 viewer 勾过菜单的状态；还原后重测是 403。种子状态 vs 中途状态要分清。

### 顺手修的两个既有 bug
