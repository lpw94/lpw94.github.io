## 锁屏改为纯手动（86baa3c）
- 现象：打开站点直接是锁屏，看不到首页。
- 根因有两处都在 `src/components/Layout.tsx`：
  ① 「首页首次进入自动弹一次」——`sessionStorage.getItem('lock-screen-seen')` 判断，
     每次新会话都触发（关掉浏览器 / 换设备就再来一次），所以"新打开就是锁屏"；
  ② 「2 分钟无操作自动锁」的空闲定时器（监听 mousemove 等 6 个事件重挂 timer）。
- 处理：两个 `useEffect` 整块删除，`lock-screen-seen` 这个 key 随之不再使用；
  顶栏 🔒 按钮逻辑原样保留（`pathname !== '/'` 时先 navigate('/') 再 setLocked(true)）。
- 验证：dev server + Chrome `--user-data-dir` 全新 profile（相当于新会话）截 `/`，
  直接显示首页文章列表（34 篇），无遮罩。**这个姿势可用来复现/验证"首次访问"类逻辑。**

## 文章页相关文章撑破移动端（bf9f6f9）
- 现象：手机上文章详情页整页横向溢出，截图里连顶栏都被推到左边。
- 定位手法（可复用）：`--remote-debugging-port=9222` 起 headless Chrome + 自写 CDP 脚本
  （`cdp-probe.mjs`：Emulation 设 390×844 移动指标 → Runtime.evaluate 遍历 body 所有元素，
  过滤掉「有 overflow 祖先裁切」的，只报真正把文档撑宽的元素 → 打印 docScrollW → 截图）。
  **注意：9222 这次监听的是 IPv4 `127.0.0.1`，不是 IPv6**，脚本里两个都试才稳。
- 实测：vw 390 / docScrollW 666，最大元素是 `li` 与 `a.related-card` 宽 641。
  根因 `.related-list` 是 `display:grid` 但没写列定义 → 隐式列按 max-content，
  而 `.related-title` 是 `nowrap`（靠 ellipsis 收尾），于是整列被标题撑开。
- 修法 `.related-list { grid-template-columns: minmax(0, 1fr) }` + `.related-card { min-width: 0 }`。
  修复后 docScrollW 390、泄漏元素 0，截图中标题正常截断为省略号。
- 已上线：`116ed48..bf9f6f9 main -> main`。线上用同一支 CDP 脚本复测
  `https://lpw94.github.io/post/blog-mobile-optimization`：vw 390 / docScrollW 390 /
  leakedCount 0，4 张相关卡片均在屏内、标题省略号正常。
