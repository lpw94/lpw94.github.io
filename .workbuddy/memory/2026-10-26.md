# 2026-10-26

## 放映厅加登录墙（/cinema 需登录）

**需求**：放映厅登录才可以看到。

**做法**（照抄 Notes 的成熟模式，不引入 AuthContext）
- `Cinema.tsx` 顶部加 `user` / `booting` / `showLogin` 三个 state
- `useEffect` 里 `supabase.auth.getSession()` 恢复会话 + `onAuthStateChange` 订阅
  （魔法链接回调时 URL token 是异步解析的，只查一次会误判未登录）
- 两个 early return 放在**所有 hooks 之后**、主 return 之前：
  `if (booting)` → 「加载中…」；`if (!user)` → `.login-gate` + `LoginModal redirectTo="/cinema"`
- 未登录时片单与三个 iframe **一概不渲染**（实测 iframe 数 0），也就不会去拉第三方资源
- 登录墙带 `<meta name="robots" content="noindex, nofollow" />`
- `scripts/gh-pages.mjs` 的 `staticPages` 去掉 `/cinema` —— 登录墙页面不该进 sitemap
- 导航入口：一开始保留（未登录点进去弹登录框）。用户随后要求「入口登录后才显示」，
  已改成 `{user && <Link to="/cinema">放映厅</Link>}`（`Layout.tsx` 第 175 行），与记事本一致。
**顺带修的文案**：`LoginModal` 标题原来写死「后台登录」，记事本/放映厅也显示这句。
改成按 `redirectTo` 派生：`/admin` → 「后台登录」，其它 → 「登录后继续」。

**顺带加的样式**：`.login-gate` 之前只有类名没有 CSS（Admin / Notes / Cinema 三处在用），
空卡里一行小字贴着顶部。补成 flex 居中 + `min-height:46vh`，三处一起受益。

**实测（CDP 1440×900 / 390×844）**
- 未登录：`.login-gate` 存在、文案「放映厅只对用户开放，请先登录后观看。」、自动弹登录框、
  `.cinema-tab` 0 个、`.cinema-item` 0 个、iframe 0 个、`meta[robots]=noindex, nofollow`
- 关掉弹窗 → 显示「点击登录」链接；点它重新弹窗
- 伪造未过期 session 写进 `localStorage['sb-<ref>-auth-token']` 后刷新：
  gate 消失、3 个 tab、6 个片单卡片、标题「放映厅」→ 登录后分支无回归
- 390 宽 docScrollW 390 无溢出

**验证技巧**：本机 supabase.co 被墙，没法真登录。`getSession()` 只读 localStorage 不校验签名，
写一份 `{access_token, expires_at: now+3600, refresh_token, user:{...}}` 到
`sb-grinllviahukzgbxvmhz-auth-token` 就能骗过登录墙，用来测「已登录」分支，比改代码临时跳过判断安全。
