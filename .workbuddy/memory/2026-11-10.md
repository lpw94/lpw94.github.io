## 飞行动画收敛（用户反馈「不要太明显」）

- 只改 `src/components/VisitorMap.tsx`，`flylines.ts` / 数据 / 头像 / 图例都没动。
  原来 35 条线同时有 16px 白色实心光点、5 种鲜艳尾迹、30fps 全量刷新，视觉太吵。
- 收敛方式（想再调就找这几个常量）：
  - **同帧活跃数**：新增 `ACTIVE_RATIO = 0.28`，每条线只在自己周期前 28% 飞行，
    其余时间不生成 geometries；35 条线相位错开后平均同帧约 10 个光点。
    注意 `path.forEach` 里用 `return` 跳过休息中的线，不是停止整个动画。
  - **淡入淡出**：新增 `FLY_ICON_DIM`（更小更淡）+ 第二档 MarkerStyle `fly-dim`，
    按 `fade = min(1, t/0.18, (1-t)/0.18) < 0.55` 选样式，光点不会在深圳突然冒出。
  - **亮度**：`TRAIL_COLORS` 由 5 种亮色改为统一冷色系 `rgba(...,0.32~0.42)`，
    尾迹 width 3→2、长度 6→4 点；静态弧线 alpha 0.28→0.16；
    光点 16px 白色实心 → 10px `#7dd3fc` 半透明。
  - **速度/帧率**：`ts*0.00018~0.00026` → `0.00011~0.000158`，节流 32ms→50ms（~20fps）。
- 验证：`npm run build` 通过；CDP 断言 3.2s 内 43 次 `setGeometries`，
  `flyMin=9 / flyMax=11 / flyAvg=9.7`（原 35）、`trailAvg=9.4`、
  `dimFrames=39/43` 淡化样式生效、`errors=[]`、图例与 canvas 正常。
  验证脚本 `scripts/publish/expr-verify-visitor-map.js` 已改为统计光点数量分布。
