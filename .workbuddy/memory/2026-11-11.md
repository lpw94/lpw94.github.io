## 新增独立游戏路由：几猫3A大作（iframe 嵌入单文件 HTML）

- 需求「首页新增一个游戏路由，嵌入 `E:/workBuddy/几猫国产3A大作_V1.html`」。
  源文件 1.4M / 6214 行，**完全自包含**：内联 Three.js（压在 `<script>` 里）、程序化生成港区场景、
  无外部 `src`/`href`；3 个 `fetch` 都是 Three.FileLoader / ImageBitmapLoader 的实现，没有实际外链；
  `localStorage` 只存画质/音量/FOV 设置。游戏暴露 `window.__ready / __frames / __errors / __fatal`，
  **验证游戏是否真跑起来直接读这几个全局**，比截图可靠。
- 方案：不转 JSX、不塞进 GameCenter 弹窗（弹窗太小装不下 3D FPS），用 iframe 隔离游戏自己的
  `position:fixed inset:0` 全屏样式、键盘监听与 rAF，避免污染主站。
  - `public/games/jimao-3a.html`：复制源文件并改成 ASCII 名（避免中文 URL 编码），
    Vite build 原样复制到 `dist/games/`。
  - `src/pages/JimaoGame.tsx`（新建）：iframe + 全屏 / 重新加载（换 key 强制重载）/ 新窗口打开 / 返回首页。
    `allow="autoplay; fullscreen; pointer-lock; gamepad"` —— **pointer-lock 必须显式给，
    否则 iframe 里 FPS 的鼠标锁定会被 Permissions Policy 拦掉**；另加 `allowFullScreen`。
    全屏是让 `.game-embed-frame.requestFullscreen()`，`:fullscreen` 时铺满视口。
    Helmet 加 `noindex`（正文只有一个 iframe，SEO 无意义）。
  - `src/App.tsx`：`<Route path="/game/jimao" element={<JimaoGame />} />`。
  - `src/components/Layout.tsx`：`showProfile` 加 `!pathname.startsWith('/game/jimao')`，
    游戏页隐藏两侧栏、正文走无侧栏的 1000px 容器；用 `startsWith` 兼容尾斜杠 / query。
  - 入口两处：`Home.tsx` 分类筛选上方的深色 banner（**移动端唯一可见入口**，
    因为 ≤720px 时两侧栏全隐藏）、`GameCenter.tsx` 右栏小游戏卡片里的独立入口，
    都用 `<Link>` 走 SPA，不刷新页面。
  - `src/styles/index.css` 末尾新增 `.game-promo / .gc-feature / .game-embed-*`。
    `.game-promo-body` / `.gc-feature-text` 都写 `min-width:0`（老坑：flex + nowrap 撑破整页）；
    720 断点里**重新声明** `.game-embed-frame` 的 height（防「按比例容器被断点写死高度」老坑）。
- `scripts/gh-pages.mjs` 的 `staticPages` **不加** `/game/jimao`（noindex，与 /cinema 一致）。
- 本地脚本 `scripts/publish/run-once.mjs` 增加可选第 6 参 `--window-size`（窄屏验证用），
  默认不传，不影响其它验证脚本。
