- 本机网络坑：curl / 系统命令行 / node fetch 到 `*.supabase.co` 全部失败
  （schannel SSL 握手失败 / Recv failure Connection reset / ECONNRESET），
  而 baidu、api.github.com 正常 → 是该域名被阻断，不是整体断网。
  Chrome headless 访问同一 REST 端点能正常返回 JSON → 请求必须放到浏览器上下文里发。
- 可复用方案（脚本放系统 temp，因 .workbuddy/tmp 会被自动清理）：
  `cdp-eval.mjs`（注入 + 轮询式求值器）+ `expr-publish.js`（按 slug 幂等 upsert 模板）。
  三个关键点：① Chrome DevTools 只监听 IPv6，必须连 `http://[::1]:9222/json/list`；
  ② `awaitPromise` 在 about:blank 会因页面节流卡死 → 改为注入 `window.__r` + 轮询；
  ③ 表达式文件必须是单个表达式（async IIFE），不能有顶层语句或开头分号（会被包进括号求值）。
- 已用假 key 验证到 `401 Invalid API key`，链路与代码路径正确，只差真实 key。
