# 2026-11-09

## 锁屏改成「模拟生态鱼缸」

**动机**：原来的锁屏是渐变底 + 漂浮 emoji，太素。改成纯 Canvas 实时演算的生态鱼缸，
不用任何图片 / 第三方库（本机 jsdelivr 不通，也不想加素材依赖）。

### 文件
- 新建 `src/components/FishTank.tsx`：Canvas 鱼缸
  - 层次：水体渐变 → 水面波纹 → 光柱 → 浮游颗粒 → 沙床+卵石 → 水草 → 气泡 → 鱼 → 涟漪
  - 鱼 7~15 条（按面积），6 种配色（小丑鱼带白条纹），身体用 bezier，尾鳍按 `sin(phase*2)` 摆动；
    每 1/4 的鱼标 `far`：小 26%、半透明 55%，充当远景做景深
  - 行为：`ty` 目标高度缓慢巡游 + 边界翻转方向；鼠标 175px 内被推离并掉头
  - 光柱**预渲染**到半分辨率离屏 canvas（`filter: blur(7px)` ≈ 屏幕 14px 柔边），
    每帧只 `drawImage` 一次并做极缓慢横移，避免每帧画 5 条硬边多边形（第一版硬边很出戏）
  - 点击水面 → 涟漪扩散 + 7 个气泡；气泡数组兜底 90 个，防止连点越来越卡
  - `prefers-reduced-motion` 只画静态一帧；`visibilitychange` 隐藏时停 rAF
  - 窄屏（<720）`pickTy()` 把鱼限制在**上 / 下两条水带**，否则全被登录卡挡住看不见
- 改 `src/components/LockScreen.tsx`：删掉 FLOATERS / floaters，换成 `<FishTank />` + `.tank-glass` 反光层 + 左上「生态鱼缸 · 实时」徽标；文案改水下主题（「算对了开门」「点一下水面会冒气泡」）
- 改 `src/styles/index.css`：整块重写锁屏样式（`.lock-screen` / `.lock-tank` / `.tank-glass` / `.tank-badge` / `.lock-card`）
  - 卡片 = 半透明深青 + `backdrop-filter: blur(14px)` 的玻璃面板，鱼在卡后面是虚化光斑
  - 输入框换成深色玻璃、按钮青绿渐变；手机端表格收紧（卡高 421→389）

### 实测（CDP，1440×900 与 390×844）
- canvas CSS 尺寸 = 视口，`devicePixelRatio` 上限 2；`docScrollWidth` 桌面 1440 / 手机 390，无横向溢出
- rAF 帧率两边都 ≈61fps
- 鼠标移过鱼会掉头；点水面出涟漪；打字 + Enter 能正常解锁（卡片消失）
- 手机卡片 358×389，上下各留一条水带，鱼可见

### 踩到的坑
- **CDP 模拟 Enter 不会触发表单提交**：`Input.dispatchKeyEvent` 只给 `key/code/windowsVirtualKeyCode` 时
  浏览器默认的「回车提交表单」不生效，必须再带 `text: '\r'` 和 `unmodifiedText: '\r'`。
  一开始误以为是表单逻辑坏了，其实 `requestSubmit()` 一直是好的。
- 光柱用每帧硬边多边形会显出明显的竖条纹边界，改成预渲染 + blur 才自然。
